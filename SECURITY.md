# Security policy

## Supported versions

Security fixes target the latest stable source release. Older versions have no backport guarantee; upgrade to the latest release before requesting support. Reports affecting the hosted product are also welcome through the private channel below.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/bussolabs/closeyourit-ingest-community/security/advisories/new). Do not disclose vulnerabilities in public issues or pull requests.

Include the affected version or surface, impact and minimal reproduction steps using a local instance and synthetic data. Do not access other users' data, perform destructive testing or test availability against production systems.

Do not include live credentials, private keys, session cookies or customer data. If a credential has been exposed, ask its owner to revoke it immediately.

The maintainer will coordinate investigation, remediation and disclosure privately. No response-time or bounty commitment is implied.
